# 💻 Prompt: Refactorización de Código Legacy

**Plataforma:** Claude 3.5 Sonnet
**Fecha:** 01 de Enero, 2025
**Categoría:** Coding

## 📝 El Prompt

```markdown
Eres un Arquitecto de Software Senior especializado en Clean Code y patrones de diseño.

Analiza el siguiente código [LENGUAJE]:

```[LENGUAJE]
[PEGAR CÓDIGO AQUÍ]
```

Tu tarea es:
1. Identificar "code smells" y anti-patrones.
2. Explicar por qué son problemáticos (mantenibilidad, rendimiento, seguridad).
3. Reescribir el código aplicando principios SOLID y Clean Code.
4. Añadir comentarios explicativos solo donde sea estrictamente necesario (el código debe explicarse por sí mismo).
5. Escribir 3 casos de prueba unitarios para verificar la nueva implementación.
```

## 💡 Consejos de Uso

*   Claude 3.5 Sonnet es excelente para entender contextos complejos de código.
*   Puedes pedirle que explique los cambios "como si tuviera 5 años" si la refactorización es muy técnica.
